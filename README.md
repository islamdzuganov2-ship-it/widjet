# Гео-приват — стеклянный виджет приватности геолокации

Современный полупрозрачный десктоп-виджет (Electron) для Windows 11. Показывает, **кто обращается к вашей геолокации**, даёт **осознанно разрешать/запрещать** доступ через штатные механизмы Windows и отображает **страну/таймзону** — не меняя системные часы.

## Что делает

1. **Аудит и журнал.** Читает штатный журнал Windows
   `CapabilityAccessManager\ConsentStore\location` (реестр) и показывает приложения
   (Store и классические Win32), которые запрашивали расположение, их текущий статус
   (разрешено / запрещено / спрашивать) и время последнего доступа. Отметка «сейчас
   активно» — если приложение использует геолокацию прямо сейчас. Только чтение,
   ничего не блокируется скрытно.

2. **Осознанное управление разрешениями.** Кнопки «Разр./Запр.» пишут тот же
   параметр `Value` (Allow/Deny), что и системное приложение
   «Параметры → Конфиденциальность → Расположение». Это штатный механизм Windows,
   без обхода. Меняются только пользовательские разрешения (HKCU), без прав
   администратора. Кнопка «Настройки Windows» открывает системную страницу.

3. **Страна / таймзона.** Определяются по системной таймзоне (офлайн, без внешних
   запросов). Кнопка «Уточнить по IP» — по желанию делает внешний запрос к публичному
   geo-IP сервису. **Системные часы компьютера не изменяются** — показывается только
   информация.

## Запуск

```bash
npm install
npm start
```

Проверить аудит из консоли (без UI):

```bash
npm run audit
```

## Границы (честно)

- «Сайты» в браузере отображаются как запись самого браузера (Chrome/Edge/…), потому
  что ОС учитывает доступ на уровне приложения. Полный пер-сайтовый аудит внутри
  браузера требует отдельного расширения браузера — это вне текущего виджета.
- Виджет **не** подменяет местоположение, **не** останавливает чужие процессы и
  **не** меняет системное время. Он только показывает и помогает управлять штатными
  разрешениями.

## Технологии

Electron · PowerShell (чтение/запись ConsentStore) · HTML/CSS (frosted glass) · без внешних зависимостей рантайма.
